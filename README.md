# 🍥 أنمي فلكس (AnimeFlix)

موقع عربي لاكتشاف ومتابعة الأنميات — واجهة أمامية كاملة (Frontend) بدون أي عملية بناء (build)، تعمل مباشرة كملفات HTML/CSS/JS ثابتة.

## ✅ المميزات المُنفّذة

- الصفحة الرئيسية: الرائج، حلقات اليوم، الأعلى تقييمًا، أحدث الإضافات
- صفحة تفاصيل الأنمي: الغلاف، القصة، التصنيفات، الحلقات، المواسم، التقييم، أعمال مشابهة
- بحث بالاسم + فلاتر (تصنيف، سنة، استوديو)
- حساب مستخدم تجريبي (تسجيل دخول/إنشاء حساب) محفوظ محليًا في المتصفح
- قائمة المشاهدة، المفضلة، سجل المشاهدة
- تعليقات وتقييمات محلية لكل أنمي
- زر "🎲 اقترح لي أنمي"
- شريط "مباشر الآن" يعرض حلقات اليوم
- الوضع الليلي/الفاتح 🌙☀️
- تصميم متجاوب بالكامل للموبايل + شريط تنقل سفلي

## ⚠️ نقاط مهمة قبل الاستخدام الفعلي

1. **البيانات وهمية بالكامل** (ملف `js/data.js`) — 8 أنميات تجريبية بأغلفة عشوائية من Picsum. استبدلها ببياناتك الحقيقية أو اربطها بقاعدة بيانات/API.
2. **لا يوجد سيرفر أو قاعدة بيانات حقيقية.** تسجيل الدخول، المفضلة، والتعليقات كلها محفوظة في `localStorage` على متصفح كل زائر فقط (تجربة تفاعلية للعرض، وليست نظام حسابات حقيقي — كل مستخدم يرى بياناته هو فقط في جهازه).
3. **حقوق الملكية:** لا تقم برفع أو بث حلقات أنمي محمية بحقوق نشر بدون ترخيص رسمي. الأنميات القليلة جدًا التي أصبحت "public domain" فعليًا نادرة جدًا، لأن حماية النشر تمتد لعشرات السنين في اليابان وأغلب الدول. الخيارات الآمنة قانونيًا:
   - اجعل الموقع "دليل أنمي" (معلومات، تقييمات، قوائم متابعة) ثم اربط المستخدم بمنصات مرخّصة رسميًا لمشاهدة الحلقة
   - أو تعاقد مع جهة توزيع مرخّصة توفر لك API/embed رسمي

## ☁️ النشر على Vercel

الموقع ثابت (Static) بالكامل ولا يحتاج أي أمر بناء:

- **Framework Preset:** Other
- **Build Command:** (اتركه فارغًا)
- **Output Directory:** `.`

فقط اربط الريبو من لوحة Vercel وسيُنشر تلقائيًا على الرابط الظاهر في صفحة GitHub الخاصة بك.

## 🗂️ هيكل الملفات

```
├── index.html       الرئيسية
├── anime.html        تفاصيل الأنمي (?id=slug)
├── search.html        البحث والفلاتر
├── login.html         تسجيل الدخول / إنشاء حساب
├── profile.html        الحساب، القوائم، الإشعارات
├── css/style.css       كل التنسيقات
└── js/
    ├── data.js         بيانات الأنميات (استبدلها ببياناتك)
    └── app.js          المنطق العام (تخزين محلي، بحث، ثيم...)
```

- اقتراحات بالذكاء الاصطناعي حسب سجل المشاهدة الفعلي
- صفحة أخبار الأنمي وجدول نزول الحلقات الأسبوعي
- ترتيب أسبوعي فعلي مبني على تفاعل المستخدمين
